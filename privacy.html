Privacy Policy

Little Wonder Auto · Last updated: September 13, 2026

Little Wonder Auto is a private application, run locally by its sole operator, used to create and publish the "Little Wonder Tales" children's story videos. It has no public website, no user accounts, and no general public users. This policy explains how the Application handles data in connection with the third-party platforms it publishes to, such as TikTok.

1. Who This Policy Covers

This policy describes the data practices of Little Wonder Auto ("the Application"), a private software tool operated solely by its Operator. It does not describe a public website or a multi-user online service, because the Application is neither.

2. What Little Wonder Auto Is

Little Wonder Auto runs entirely on the Operator's own personal computer. It is used to generate children's story video content and to publish that content to platforms the Operator has personally connected, including YouTube, TikTok, and Instagram. It has no server that the public can access, no sign-up flow, and no accounts belonging to anyone other than the Operator.

3. Information the Application Processes

The Application processes the following categories of information, all in connection with the Operator's own use:

  • Platform authorization tokens (OAuth): when the Operator connects a platform such as TikTok, YouTube, or Instagram, that platform's own official authorization process issues an access token (and, where applicable, a refresh token) to the Application. This token is used only to publish the Operator's own video content to the Operator's own authorized account, and to check that the connection is still valid.
  • Generated content and project data: story text, images, video, and audio created by the Application, along with related project metadata (such as scene descriptions and publishing status), are stored locally on the Operator's own device to produce and track each video project.

The Application does not have viewer-facing accounts, forms, or interfaces of any kind, and therefore does not collect personal information from viewers of the published videos or from any member of the public.

4. Third-Party Services Used to Generate Content

To produce story, image, video, and audio content, the Application makes API calls to third-party AI content-generation providers. Only the content needed to generate that specific piece of media (for example, a scene description) is sent to those providers for that purpose. No third-party platform's user data, and no personal data about video viewers, is sent to these content-generation providers.

5. How TikTok and Other Platform Connections Work

When the Operator chooses to connect TikTok (or another supported platform), the Application opens that platform's own official OAuth authorization page. The platform — not the Application — collects the Operator's login credentials directly; the Application never sees or stores the Operator's platform password. Once authorized, the platform provides the Application with an access token scoped to the specific permissions the Operator approved (for example, the ability to publish a video on the Operator's own behalf).

6. How OAuth Tokens Are Stored and Protected

Access and refresh tokens are stored only in local files on the Operator's own computer. These files are:

  • Never uploaded to any public server, website, or third-party service other than the platform that issued them;
  • Never included in any code, repository, or file made public — including the pages you are reading now;
  • Never sold, rented, or shared with any third party;
  • Used only to make the specific, authorized API calls needed to publish the Operator's own content or check connection status.

Because the Application and its stored data reside entirely on the Operator's own device, they are not exposed to the public internet by the Application itself.

7. Data Retention and Deletion

A platform's token is kept only for as long as that platform connection remains active. The Operator can disconnect a platform at any time from within the Application, which removes the locally stored token for that platform. Because all data is stored locally, the Operator may also delete any or all of it directly at any time.

8. Children's Privacy

The video content produced using the Application is intended for a family and children audience. However, the Application itself does not knowingly collect personal information from children or from any other individual, because it has no viewer-facing accounts, forms, comments, or other means of collecting information from the people who watch the published videos.

9. Security

The Operator takes reasonable steps to keep locally stored credentials from being exposed publicly — for example, by keeping token files out of any published or shared code. No method of electronic storage is completely secure, and the Application does not claim to guarantee absolute security.

10. Changes to This Policy

This policy may be updated from time to time to reflect changes in how the Application operates or to satisfy the requirements of a connected third-party platform. The "Last updated" date at the top of this page reflects the most recent revision.
